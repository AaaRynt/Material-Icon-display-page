# Material Icon display page

A simple page to display both **files** and **folders** icons based upon [Material Icon](https://github.com/material-extensions/vscode-material-icon-theme?tab=readme-ov-file) and [VS Code Icon](https://github.com/vscode-icons/vscode-icons)

## Winter Vacation Musings

I program it to getting used to [Tailwindcss](https://github.com/tailwindlabs/tailwindcss). on a boring afternoon.

It unintentionally became a record of a rare, calm period of time. Perhaps I didn't fully realize that this period would be one of the few days I would spend in the **real sunshine** in the future.
